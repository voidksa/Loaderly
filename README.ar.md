أضف رابطًا أو ملفًا من جهازك، وعدّل المقطع ثم صدّره من مساحة واحدة. يجمع Loaderly التنزيلات والمكتبة وتعديل الفيديو والصوت والترجمة وتصاميم المجتمع، بواجهة وأدلة مصوّرة بالإنجليزية والعربية.

## التنزيل

| جهازك | رابط التنزيل |
| --- | --- |
| ويندوز 10 أو 11 بمعمارية 64 بت | [تنزيل من Microsoft Store](https://apps.microsoft.com/detail/9N1R1H10HXR7) |
| ماك بمعالج Apple Silicon | [نسخة Apple Silicon](https://loaderly.app/download?platform=macArm) |
| ماك بمعالج Intel | [نسخة Intel](https://loaderly.app/download?platform=macIntel) |
| Ubuntu أو Debian بمعمارية 64 بت | [حزمة DEB](https://loaderly.app/download?platform=linuxDeb) |
| توزيعات لينكس الأخرى المتوافقة بمعمارية 64 بت | [ملف AppImage](https://loaderly.app/download?platform=linuxImage) |

نسخة ويندوز وتحديثاتها التالية متاحة عبر Microsoft Store فقط. إذا كنت تستخدم نسخة ويندوز القديمة من خارج المتجر، ثبّت نسخة المتجر وتحقق من مكتبتك وإعداداتك قبل إزالة النسخة القديمة.

اتبع [دليل التثبيت](https://loaderly.app/ar/docs/installation/) الخاص بنظامك. يحتفظ التحديث بمكتبتك وإعداداتك. أنهِ التنزيلات والتصدير قبل التثبيت.

## الجديد في 2.3.2

- **اعرف متى يتوفر تحديث المتجر:** يفحص ويندوز تلقائيًا وينزّل التحديث أثناء عملك. احفظ وثبّت بعد انتهاء المهام.
- **أكمل التنزيلات المتوقفة:** الاحتفاظ بالبيانات الجزئية وطريقة النقل واختيار الاستبدال أو الاحتفاظ بالنسختين للمهمة نفسها.
- **احتفظ بحساب المجتمع:** تعذّر الاتصال المؤقت لا يخفي تسجيل دخولك المحفوظ، مع استعادة الجلسة المحمية بعد إعادة الفتح أو التحديث.
- **بدّل المظهر بوضوح:** اختيار ثيم أساسي يستبدل ألوان التصميم السابق وتنسيقه. لم يعد المظهر المخصص يُظهر ثيمًا أساسيًا كمحدد.
- **أغلق التنبيه بسهولة:** زر إغلاق متوسّط الأيقونة مع تركيز واضح للوحة المفاتيح بالعربي والإنجليزي.

[استعرض دليل 2.3.2](https://loaderly.app/ar/docs/whats-new/). يوفّر Microsoft Store نسخة ويندوز المنشورة حاليًا.

## مساحة واحدة للفيديو والصوت

نزّل الصوت الأصلي أو الغناء فقط أو الموسيقى بدون غناء. عدّل الفيديو والصوت، وقلل الضوضاء، وأضف النصوص، وصمّم أطيافًا صوتية، ثم صدّر عملك. احتفظ بمشاريع قابلة للنقل ونسخ تحرير مسماة، أو صدّر عدة مقاطع بإعدادات مستقلة. أضف الروابط بالزر العائم أو الالتقاط التلقائي أو اختصارات قابلة للتخصيص.

![اختيار الصوت الأصلي أو الأصوات البشرية أو الموسيقى](docs/images/loaderly-downloads-ar.png)

## المشاركة من Loaderly

1. افتح **مكتبة المجتمع ← تصميم ومشاركة**.
2. اختر **ثيم جديد** أو **طيف جديد** أو **إعداد صوت جديد**. يبدأ التصميم بإعداداتك الحالية. إذا عندك ملف إعدادات أو كود جاهز اختر **استيراد تصميم**.
3. اكتب اسم التصميم وجرّبه. للصوت اختر **جرّب صوتك** وقارن **الصوت الأصلي** بـ**الصوت المعدّل**.
4. سجّل الدخول واختر **نشر في مجتمع Loaderly**. يفتح **عرض منشوري** النسخة العامة.
5. تبقى التعديلات اللاحقة خاصة حتى تضغط **نشر التحديث**.

سجّل الدخول بحساب **GitHub** داخل Loaderly للنشر. يظهر تصميمك في البرنامج و[موقع المجتمع](https://loaderly.app/ar/community/). يشرح [الدليل المصوّر](https://loaderly.app/ar/docs/community/) المسودات والنشر والتحديث.

## ابدأ بمقطع واحد

اختر **المكتبة ← استيراد** وحدد فيديو أو صوتًا ثم **فتح المحرر**. شاهد تعديلاتك واستمع إليها في المعاينة. عند التصدير، احفظ نسخة معدلة بجانب الأصل، أو اختر مكانًا آخر، أو استبدل الأصل عند تطابق الصيغة. ولا يُستبدل الأصل إلا بعد اكتمال التصدير بنجاح.
