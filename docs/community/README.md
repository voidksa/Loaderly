## Use a starter design

1. Download the theme or visualizer JSON file above.
2. Open **Community library → Create & share → Import design** in Loaderly.
3. Choose **Import settings file**, select the downloaded file, then review and apply the design.
4. For a visualizer, open an audio clip and press **Play** to see it respond to your sound. **Clean view** hides the editing controls; <kbd>Esc</kbd> returns to editing.

Theme files include light and dark colors. Visualizer files contain appearance settings only; the motion follows your audio.

## Share your version

Open **Community library > Create & share** in Loaderly. Sign in with GitHub, create or import a theme, visualizer or sound preset, then choose **Publish in Loaderly**. Your design appears in the app and on the [community website](https://loaderly.app/community/). Use **Publish update** after editing. GitHub is used for sign-in. Publishing happens in Loaderly.

[Theme guide](https://loaderly.app/docs/appearance/) · [Visualizer designer and guide](https://loaderly.app/docs/audio-visualizer/#visualizer-builder)
