# Community starter looks

Two ready-to-use examples for Loaderly 2.0. Use them as they are or remix them into your own designs.

| Look | Preview | Code |
| --- | --- | --- |
| **Mint Slate** app theme | [Dark](mint-slate-dark.png) · [Light](mint-slate-light.png) | [Theme code](mint-slate.theme.json) |
| **Aurora Orbit** audio visualizer | [Clean view](aurora-orbit-preview.png) · [In the editor](aurora-orbit-editor.png) | [Visualizer code](aurora-orbit.visualizer.json) |

## Apply Mint Slate

1. Copy the complete theme code.
2. In Loaderly, open **Preferences → General → Share or import a theme**.
3. Paste into **Theme code**, then choose **Apply code**.
4. Choose **Dark** or **Light** from the Theme menu to try each palette.

The same code includes both palettes. You can also save the JSON file and choose **Import file** in the same section.

## Apply Aurora Orbit

1. Open an audio file in Loaderly's editor, or extract audio from a video.
2. Open **Audio → Visualizer → Share this look**.
3. Paste the complete visualizer code into **Visualizer code**, then choose **Apply look**.
4. Press **Play** to see it react to your audio. **Clean view** hides the editor for screen recording; **Escape** returns to editing.

The code contains the look only. Its motion follows your audio, so the bars will vary from the screenshot.

## Share your version

After changing colors, size or movement, use **Copy code** for a theme or **Copy look** for a visualizer. Create a discussion in [App themes](https://github.com/voidksa/Loaderly/discussions/categories/app-themes) or [Audio visualizers](https://github.com/voidksa/Loaderly/discussions/categories/audio-visualizers), and add a name, a screenshot and the complete code. Mention the original if you remix someone else's look.

[Theme guide](https://loaderly-docs.voidksa.workers.dev/docs/appearance/) · [Visualizer designer and guide](https://loaderly-docs.voidksa.workers.dev/docs/audio-visualizer/#visualizer-builder)
